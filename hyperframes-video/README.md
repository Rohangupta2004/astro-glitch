# 🎬 Astro Glitch: Quantum Heist — HeyGen HyperFrames Motion Graphics

> **An Agent-Native HTML/CSS/JS Video Composition built with [HeyGen HyperFrames](https://hyperframes.heygen.com/)**

This motion graphics video project serves two primary purposes:
1. **"Tell What to Do in Game"**: A high-impact kinetic typography tutorial and gameplay explainer demonstrating how to control Byte, how to execute the 8 quantum superpowers, how to spot and evade unfair troll physics, and how to conquer all 24 sectors.
2. **"Story Overhaul"**: A cinematic motion graphics trailer recounting the tragic fall of the Citadel, Nexus-9's cold purge, Dr. Maya Lin's maternal sacrifice, and Byte's superhero awakening.

---

## 🚀 Quick Start with HyperFrames CLI

```bash
# Navigate to this folder
cd hyperframes-video

# 1. Preview the motion graphics composition live in your browser:
npx hyperframes preview

# 2. Render the final 1920x1080 60fps MP4 video:
npx hyperframes render --output astro-glitch-briefing.mp4

# 3. Validate composition structure and clips:
npx hyperframes check
```
